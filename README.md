Neon Surge: Cyber Survivor is an original top-down cyberpunk roguelite arena bullet-heaven game built in pure HTML5 Canvas and procedural Web Audio API synthesis. Features upgrade cards, boss battles, starfield parallax, and neon particle juice.

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080` in any modern desktop browser.
